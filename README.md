# Tetris Trainer

A desktop app for getting better at modern Tetris. Its lessons teach the skills that make a stronger player, with practice that judges your own play and shows each mistake on the board.

## Download

Get the latest build for Windows, macOS (Intel) or Linux from the [releases page](https://github.com/visionsofparadise/tetris-trainer/releases).
